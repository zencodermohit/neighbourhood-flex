# Transformer model

Download "High voltage power transformer" by Showdoze from Sketchfab
(https://sketchfab.com/3d-models/high-voltage-power-transformer-727bc7bb6777467dbea2ab6e0590bf4a)
and place it here as either:

- `transformer.glb` (Download 3D model → glb), or
- `transformer/scene.gltf` with its `scene.bin` and `textures/` (Download 3D model → glTF, unzipped)

The dashboard picks it up on the next page load. License: CC BY-NC 4.0, credit is shown in the 3D view.
Without the file, the dashboard uses its built-in transformer model.
